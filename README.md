# Chat App - Frontend

A modern real-time chat application frontend built with React, TypeScript, and Chakra UI. Features include private messaging, group chats, file sharing, emoji support, and real-time notifications.

## ✨ Features

- **User Authentication**: Register, login, and guest login
- **Real-time Messaging**: Instant message delivery with Socket.io
- **Private Chats**: One-on-one conversations
- **Group Chats**: Create and manage group conversations
- **File Sharing**: Share images, videos, and documents
- **Emoji Picker**: Express yourself with emojis
- **Message Replies**: Reply to specific messages
- **Delete Messages**: Delete for yourself or everyone
- **Read Receipts**: See when messages are read (✓, ✓✓)
- **Unread Badges**: Red notification badges for unread messages
- **Typing Indicators**: See when someone is typing
- **Profile Management**: Update profile and change password
- **Block/Unblock**: Block unwanted conversations
- **Search Users**: Find other users to chat with
- **Admin Panel**: Special interface for administrators

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **UI Library**: Chakra UI
- **State Management**: Context API
- **Routing**: React Router DOM v5
- **Real-time**: Socket.io Client
- **HTTP Client**: Axios
- **Icons**: React Icons, Chakra UI Icons
- **Emoji Picker**: emoji-picker-react
- **Animations**: react-lottie
- **Notifications**: react-hot-toast
- **File Upload**: react-dropzone
- **Forms**: react-hook-form
